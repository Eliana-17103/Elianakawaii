# FTC Team Robot Code, nya~ 🐾🤖

Hey teammates! Welcome to our robot code repo! ✨ Just follow these quick rules whenever you're working on the bot so we don't accidentally overwrite each other's hard work, okay~? 🐱💕

## Getting Started (First Time Only!) 🎀
1. Download and sign into **GitHub Desktop**.
2. Go to **File > Clone Repository** and clone this repo to your computer!
3. Open **Android Studio**, click **File > Open**, and select the cloned folder~

## Daily Coding Rules ✨
- **Never push directly to `main`, nya!** Always switch to your assigned branch first so we keep our main code safe~
- **Pull before you start:** Open GitHub Desktop and click **Fetch origin** / **Pull origin** before editing anything in Android Studio so you're always up to date!
- **Test before pushing:** Make sure your code builds without any errors in Android Studio before committing, please~ 🙏

## Team Branches 🌿
- `main` — Tested, competition-ready robot code (Locked! Needs approval before merging 💖)
- `isaac` — Just do whatever you want for now. It's not like I care or anything!
## How to Submit Your Code 💌
1. In GitHub Desktop, double-check that **Current Branch** is set to your own branch.
2. Write a clear commit summary, click **Commit**, and hit **Push origin**, nya~ 🚀
3. Head over to this repo on GitHub.com, open the **Pull requests** tab, and click **New pull request**.
4. Set **base: main** and **compare: your-branch**, then create the Pull Request so it can get reviewed and approved! ✨
